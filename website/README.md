# QA Excellence Knowledge Base - Docusaurus Website

This directory contains the Docusaurus configuration and generated documentation website for the QA Excellence Knowledge Base.

## 🚀 Quick Start

### Development
```bash
npm start
```

### Build
```bash
npm run build
```

### Deployment
The site automatically deploys to GitHub Pages when changes are pushed to the main branch.

## 📁 Structure

- `docs/` - All documentation content organized by categories
- `src/` - Custom React components and pages
- `static/` - Static assets (images, files)
- `docusaurus.config.ts` - Main configuration file
- `sidebars.ts` - Navigation structure

## 🔧 Configuration

- **Site URL**: https://user.github.io/QA-SOB/
- **Base URL**: /QA-SOB/
- **GitHub Integration**: Enabled with edit links
- **Search**: Will be configured with Algolia
- **Themes**: GitHub (light) / Dracula (dark)

## 📖 Content Organization

1. **Interview Preparation** - Complete preparation materials for Senior QA roles
