## Claude Code Instructions

### Quality Standards
- Always follow GitFlow methodology for version control
- Maintain professional documentation standards
- Use consistent formatting and structure across all documents
- Keep technical accuracy and practical applicability as top priorities

### Content Guidelines
- Focus on practical, actionable advice over theoretical concepts
- Include real-world examples and code snippets where applicable
- Maintain beginner-friendly explanations while providing advanced insights
- Structure content for easy navigation and quick reference

### Repository Maintenance
- Update content based on industry best practices evolution
- Ensure all links and references remain functional
- Maintain consistency in document templates and formatting
- Regular review of outdated technologies or methodologies

### GitFlow Workflow
- Use feature branches for new content development
- Follow conventional commit messages
- Require pull request reviews for quality assurance
- Maintain clean, professional commit history

## Document Structure Standards

### File Naming Convention
- Use kebab-case for file names
- Include descriptive, searchable titles
- Maintain consistent extension (.md for documentation)
- Use meaningful directory organization

### Content Organization
- Start with clear objectives and overview
- Use hierarchical headings (H1, H2, H3)
- Include practical examples and templates
- End with key takeaways or action items

### Formatting Standards
- Use tables for structured comparisons
- Include code blocks with appropriate syntax highlighting
- Use callout boxes for important information
- Maintain consistent emoji usage for visual enhancement
